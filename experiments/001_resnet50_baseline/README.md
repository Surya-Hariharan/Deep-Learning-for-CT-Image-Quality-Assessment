## Setup

- **Dataset:** LDCT-IQAC, 900 training / 100 validation (seeded 90/10 split
  of the 1000 labeled training images). The 300-image test set was not
  touched during training or checkpoint selection.
- **Model:** `OhashiResNet50` — RadImageNet-pretrained ResNet50 backbone →
  GAP → Dropout(0.5) → Linear(2048→1) → Sigmoid. RadImageNet weights
  verified loaded (265/318 backbone keys matched, 0 unexpected).
- **Config:** Adam, MSE loss, batch size 64, lr 1e-3, 30 epochs, seed 42.
  Full resolved config: `config.json` in this directory.

## Training result
