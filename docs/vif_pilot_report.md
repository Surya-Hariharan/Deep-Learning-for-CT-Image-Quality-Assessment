# VIF Pilot Report — Small LDCT-IQAC Sample Validation

Small-scale, real-data validation of the canonical
`vif_wavelet(profile="project")` pipeline (decision A-15, status B —
CONDITIONALLY VALIDATED per `docs/research_decisions.md`) before any
commitment to full 169,000-image dataset generation.

This is exploratory validation, not dataset production: no LDCT-IQAC
labels were written, `data/raw/ldctiqa/ground_truth_score.json` was not
touched, and `data/manifests/quality_iqa_manifest.*` was not written or
modified. All pixels and plots generated by this pilot live under
`data/interim/vif_pilot/` (covered by `.gitignore`'s `data/interim/**`
rule) and are not committed — see §11 for the Git safety audit.

Generator: `scripts/quality/vif_pilot.py`. Run date: 2026-08-13. Seed:
`20260813` (`configs/paths.yaml:random_seed`, unmodified).

---

## 1. Sample selection

30 reference images selected from the 1,000-image LDCT-IQAC manifest
(`data/manifests/ldctiqa_manifest.csv`), stratified across the
`expert_score` range (0.0–4.0) into 5 equal-width score bins, with images
drawn from each bin via `numpy.random.default_rng(20260813)`. This spreads
the sample across the full quality range rather than clustering around the
mean, per the task requirement to cover the expert-score range as well as
possible with a small n.

Full per-image record — `image_id`, `expert_score`, `selection_reason`,
`random_seed` — is written to `data/interim/vif_pilot/sample_selection.csv`
(gitignored, reproducible by re-running the script with the same seed).
Selected `expert_score` values in this run spanned **0.2 to 4.0**, covering
essentially the full labelled range (LDCT-IQAC's scale is 0.0–4.0 in 0.2
steps). No source image was modified; each was opened read-only.

## 2. Number of references

**30** (target: 20–50, per the task's stated range).

## 3. Number of generated images

**990** degraded images (30 references × 33 non-clean conditions each; the
34th condition per reference, "clean", is excluded from VIF computation
since VIF of a reference against itself is trivially ≈1.0 and was already
established analytically in `tests/test_vif_wavelet.py`).

Per-reference condition breakdown:

- 12 noise-only (full OHASHI-SPECIFIED grid: σ ∈ {1, 1.5, 2, 3, 4.5, 6, 7.5,
  9, 14, 21, 30, 50}, unreduced)
- 12 blur-only (full OHASHI-SPECIFIED grid: σ ∈ {0.1, 0.15, 0.2, 0.3, 0.45,
  0.6, 0.75, 0.9, 1.4, 2.1, 3.0, 5.0}, unreduced)
- 9 combined noise+blur — a **pilot-only** 3×3 low/medium/high subset
  (noise σ ∈ {1, 6, 50}, blur σ ∈ {0.1, 0.6, 5.0}) of the full 12×12=144
  factorial. This reduction applies to this pilot only; the actual dataset
  generator (`scripts/quality/build_ohashi_dataset.py`) still targets the
  full 144 combined conditions per reference. Chosen to keep the pilot's
  runtime tractable (990 vs. what would have been 5,070 images) while still
  covering the full severity range on both axes.

Two parameters this pilot needed but the canonical dataset generator
deliberately refuses to guess (see `docs/research_decisions.md`, U-D01/
U-D02) were given **explicit, provisional, pilot-only** values:

- `combination_order = "blur_then_noise"` — chosen as the more common
  physical-acquisition-chain convention (optical/detector blur precedes
  electronic readout noise). This does **not** resolve U-D02.
- `sigma_scale = 1.0` — treats the grid as already in the image's own
  8-bit intensity units, consistent with the existing project note on
  U-D01 (LDCT-IQAC is 8-bit). This does **not** resolve U-D01.

Neither choice is presented as settled; both remain open items for the
actual full-dataset run and must be separately confirmed and recorded
before `build_ohashi_dataset.py --execute` is ever unblocked.

## 8. Monotonicity results

**Noise-only:** 30/30 reference sequences (100%) fully monotonic — VIF
strictly decreases as noise σ increases across all 12 levels, for every
single reference image in the sample. Zero violations.

**Blur-only:** 30/30 reference sequences (100%) fully monotonic — VIF
strictly decreases as blur σ increases across all 12 levels, for every
reference. Zero violations.

**Combined (noise+blur):** analysed two ways, because the pilot script's
first-pass metric (ordering the 9 combined conditions by
`noise_sigma + blur_sigma` as a single severity proxy) turned out to be a
flawed test, not a real finding — that ordering conflates perceptually
very different combinations (e.g. noise=1,blur=5.0 and noise=6,blur=0.1
land at nearly the same "severity sum" despite being very different
distortions), so it reported 0/30 (0%) "fully monotonic," which sounds
alarming but reflects the ordering key, not the metric. Re-analysed
per-axis instead (holding one of noise/blur fixed, sweeping the other) —
the meaningful test, since it isolates one degradation dimension at a
time:

- **180 axis-wise sequences** (30 refs × 3 fixed-noise blur-sweeps + 30
  refs × 3 fixed-blur noise-sweeps).
- **30 violations (16.7%)**; **150/180 (83.3%) fully monotonic.**
- **Every single violation occurs at exactly one condition: `blur=5.0`
  fixed, sweeping noise upward** (confirmed by direct tabulation — 30/30
  violations at `blur_fixed=5.0`, 0 violations at any other fixed blur or
  any fixed-noise sweep). Worst single-step increase: **+0.104** (image
  `0422`, blur=5.0 fixed, noise sweeping 1→6→50).

**Interpretation:** at the single most severe blur level in the grid
(σ=5.0, which already crushes VIF to ~0.03–0.12 range on its own — see the
`0714` example in §11's underlying data), adding progressively more noise
on top produces a small, non-monotonic uptick rather than a further
decrease. This is a narrow, systematic, well-localized edge case — not
noise across the sample — and the magnitudes involved stay small (VIF
values in the 0.03–0.22 range throughout, i.e. the metric still correctly
signals "severely degraded" even where it isn't strictly ordering
within that severely-degraded region). Per the task's own guidance, this
is reported as a violation, not smoothed over or treated as a failure of
"perfect" monotonicity the metric was never guaranteed to have.

## 10. Low-texture diagnostics

Ran `vif_wavelet_diagnostics()` on every one of the 990 pilot images (7,920
per-subband records: 990 images × 8 subbands each), specifically checking
for the failure mode diagnosed on synthetic images in
`docs/vif_implementation.md` §13.4 (ill-conditioned GSM covariance,
channel-gain blow-up).

**Ill-conditioned covariance (the dominant synthetic-image failure mode):
NOT observed on real images.** Maximum condition number across all 7,920
subband records was **7,362** — nowhere near the flag threshold (1×10¹²)
and orders of magnitude below what the synthetic "smooth" test image
produced (1×10¹⁶–1×10¹⁸, per `docs/vif_implementation.md`). Real CT
anatomy, even in this small sample, carries enough local texture that the
GSM block-covariance estimation stays well-conditioned throughout. This is
the good news half of the low-texture investigation.

**Channel-gain instability: DOES occur on real images, more often than
expected, but does not appear to corrupt final scores in this sample.**
75% of images (742/990) show at least one subband with `g > 50`; the
maximum observed was ~2.5×10⁸. Diagnosed mechanism, confirmed by direct
inspection of the underlying data (not just the aggregate flag count):

- The reference-side local variance term (`ss_x` in
  `_distortion_channel_field`) depends only on the *reference* image and
  is therefore the same across every distortion applied to a given
  reference. Real CT images commonly contain large near-uniform regions
  (background outside the body, air pockets, bone plateaus) where this
  term is close to the numerical tolerance floor.
- In those regions, `g = cov_xy / (ss_x + tol)` is a division by a
  near-zero denominator. The estimate is inherently noise-sensitive there
  regardless of which distortion is applied.
- **This sensitivity is asymmetric between distortion types, and the data
  confirms it directly**: mean per-image max `g` was **~10.7 million**
  for noise-degraded images vs. **~3,117** for blur-degraded images (a
  ~3,400× difference). Blurring a near-flat reference region keeps the
  distorted region correspondingly near-flat, so `cov_xy` stays small
  alongside `ss_x` and the ratio stays bounded; independent per-pixel
  noise perturbs `cov_xy` stochastically even where `ss_x` is tiny,
  which is exactly what drives the blow-up.
- **Despite this, the flagged images' final VIF scores (range 0.028–0.986,
  mean 0.516) fall inside the same overall envelope as unflagged images
  (range 0.027–1.000, mean 0.847, lower degradation severity mix) — no
  flagged image produced a NaN, Inf, negative, or out-of-[0,1.5]-range
  score.** The log-based aggregation (`log2(1 + g²·s·λ/(σ_v²+σ_nsq))`)
  compounds extreme `g` values only logarithmically, and a handful of
  near-flat-region pixels are outnumbered by the much larger number of
  well-behaved pixels elsewhere in a 512×512 image — consistent with the
  theoretical expectation noted in `docs/vif_implementation.md` §13.4, now
  empirically confirmed on real images rather than only reasoned about.

**Frequency summary:**

| Diagnostic | Real LDCT-IQAC pilot (990 images) | Synthetic "smooth" test (`docs/vif_implementation.md`) |
| --- | --- | --- |
| Ill-conditioned covariance (>1e12) | 0 (0%) | Yes, every subband (~1e16–1e18) |
| Unstable channel gain (>50) | 742 (75.0%) | Yes (finest levels, up to ~2,212) |
| NaN / Inf final score | 0 (0%) | N/A (finite but VIF≫1 in that case) |
| VIF outside [0, 1.5] | 0 (0%) | Yes (VIF up to ~11.6) |

**This is the pilot's central finding.** The specific failure mode
predicted from synthetic testing (ill-conditioned covariance) essentially
does not occur on real CT images. A *related but distinct* failure mode
(channel-gain instability from near-flat background regions) occurs
frequently, but — in this 990-image sample — never propagates into a
corrupted final score. Whether this holds at 169,000-image scale, across
all degradation severities and all 1,000 references, is **not
established** by a 990-image pilot and should not be assumed.

## 12. Relationship with expert scores

**Descriptive only — not a claim of equivalence.** `expert_score` measures
radiologists' subjective assessment of the *original, undegraded* LDCT-IQAC
image (itself already containing real acquisition artifacts, per
`docs/deviations_from_ohashi.md` DEV-02). `vif_score` measures information
fidelity of a *synthetically degraded* version relative to that same
image. These are different quality signals answering different questions,
exactly as the task instructions require stating explicitly.

For descriptive context only: across the 30 sampled references, Pearson
correlation between each reference's *mean* VIF (averaged across all 33 of
its degraded variants) and that reference's `expert_score` was **0.860**
(Spearman 0.852). A plausible reading is that references with higher
expert_score (perceived as higher quality / more genuine anatomical detail
to begin with) retain more of that detail under synthetic degradation,
giving systematically higher average VIF — but this is offered as an
observation for a sample of 30, not a validated relationship, and should
not be used as a stand-in for either signal.

## 13. Problems discovered

1. **Channel-gain instability occurs on ~75% of real pilot images** (§10)
   — more frequently than the synthetic testing in
   `docs/vif_implementation.md` suggested, though without observed
   consequences for final-score sanity in this sample.
2. **A narrow, systematic combined-degradation monotonicity violation** at
   the single most-severe blur level (§8) — small in magnitude, perfectly
   localized, not present in noise-only or blur-only sequences.
3. **The pilot script's own first-draft combined-monotonicity metric was
   methodologically flawed** (ordering by `noise_sigma + blur_sigma`) and
   had to be recomputed per-axis to produce a meaningful result — recorded
   here as a process note, not a VIF problem, so a future reader does not
   mistake the discarded 0%-monotonic headline number for a real finding.
4. **`combination_order` and `sigma_scale` remain genuinely unresolved**
   (U-D01, U-D02) — this pilot used explicit, documented placeholder
   values, not a resolution.

No NaN, Inf, negative, or out-of-range VIF scores were observed anywhere
in this sample (§§5–7).

## 14. Recommendation

**B. READY WITH DOCUMENTED HANDLING RULE**

Not A: 75% of pilot images trigger a known, real (not synthetic-only)
numerical instability in the channel-gain estimation stage. Even though
this sample shows zero corrupted final scores, "no corrupted scores in
990 images" is not the same claim as "safe to run unattended and
unmonitored across 169,000 images with 1,000 references and the full
144-way combined grid" — the full run has ~170× more images and covers
severity combinations this pilot deliberately subsampled (§3). Proceeding
straight to full generation on this evidence alone would be treating a
promising pilot result as a proof it is not.

Not C: nothing here indicates an implementation defect requiring
investigation before further progress. The dominant synthetic-image
failure mode (ill-conditioned covariance) does not manifest on real
images at all (0/7,920 subbands). The channel-gain sensitivity has a
clear, verified mechanism (near-flat reference regions, an intrinsic
property of real CT images, not a bug), degrades gracefully through the
log-based aggregation in every observed case, and the combined-degradation
violation is narrow and explainable. This is evidence *for* proceeding,
under conditions — not evidence of a broken pipeline.

**Before full dataset generation, at minimum:**

- Record a documented handling rule for `UNSTABLE_CHANNEL_GAIN`-flagged
  records: e.g., retain the VIF score (do not clip/discard/silently
  replace, per this pilot's own instructions) but propagate the
  diagnostic flag into the manifest as a queryable column, so downstream
  training/evaluation can audit or optionally exclude flagged records
  without the flag itself ever silently altering a label.
- Resolve, or explicitly re-affirm as provisional-but-committed,
  `combination_order` (U-D02) and `sigma_scale` (U-D01) before they are
  baked into 169,000 irreversible labels — this pilot's choices were
  reasonable placeholders, not resolutions.
- Consider re-running this same pilot methodology at a larger sample size
  (e.g. 100–150 references, full 144-way combined grid) specifically to
  check whether the channel-gain instability rate (75% here) or the
  blur=5.0 monotonicity violation change in frequency or severity at
  larger scale, before the irreversible full run.
