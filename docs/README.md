# Documentation index

Start with the root [`README.md`](../README.md) for project overview,
installation, and how to run training/evaluation. This folder holds the
detailed material that README links out to:

- **[`paper/`](paper/)** — what the reference paper (Ohashi et al.)
  specifies, and nothing else. If it's not in the paper, it isn't here.
- **[`replication/`](replication/)** — how *this project* adapts that
  methodology: dataset differences, implementation decisions where the
  paper is silent, reproducibility notes, and the full results writeup.
- **[`internal/`](internal/)** — engineering/process history for this
  repository (structure audits, a decisions log). Not needed to install,
  run, or understand the project — kept for provenance only.
